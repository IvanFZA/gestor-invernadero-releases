# 🌱 Gestor de Invernaderos — Versiones de prueba

Bienvenido al repositorio de distribución de la aplicación móvil **Gestor de Invernaderos**.

Este espacio está destinado a descargar versiones de prueba para Android y compartir comentarios, sugerencias o errores encontrados durante su uso.

## 📱 Descargar la aplicación

Accede a la sección **Releases** de este repositorio y descarga el archivo APK de la versión más reciente.

## 🔧 Instalación

1. Descarga el archivo APK en tu dispositivo Android.
2. Abre el archivo descargado.
3. Si Android lo solicita, permite la instalación desde esa fuente.
4. Instala y abre la aplicación.
5. Inicia sesión o crea una cuenta para comenzar las pruebas.

## 🧪 Funcionalidades que puedes probar

- Registro e inicio de sesión.
- Gestión de invernaderos.
- Programación y seguimiento de actividades.
- Calendario de actividades.
- Sincronización con Google Calendar.
- Marcado de actividades realizadas y cancelación de actividades.

## 🐛 Reportar errores o sugerencias

Si encuentras algún problema, entra a la pestaña **Issues** y selecciona **New issue**.

Incluye, de ser posible:

- Descripción del problema.
- Pasos para reproducirlo.
- Modelo del dispositivo Android.
- Versión de la aplicación.
- Captura de pantalla, sin información personal.

También puedes utilizar Issues para proponer mejoras.

## 🔒 Código fuente

Este repositorio está destinado únicamente a la distribución de versiones de prueba. El código fuente de la aplicación se mantiene en un repositorio de desarrollo independiente.

## 📌 Estado

Aplicación en fase de pruebas. Algunas funcionalidades pueden cambiar en futuras versiones.
